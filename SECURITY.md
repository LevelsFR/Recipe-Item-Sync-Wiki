# Security Policy

## Repository changes

This repository hosts the public documentation for Recipe Item Sync.

Only trusted maintainers should merge changes to the published documentation or GitHub Pages workflow.
External contributions must be submitted through Pull Requests and reviewed before being accepted.

## Reporting a security issue

Please do not publish sensitive security reports in a public issue.

Contact the project team through the Our Story Network Discord:
https://discord.gg/kb8NSTF45n
